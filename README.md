## Cách chạy trang giới thiệu

1. Đặt project trong thư mục C:\xampp\htdocs.
2. Khởi động Apache bằng XAMPP.
3. Mở trình duyệt và truy cập:
   http://localhost/thuc-hanh-lap-trinh-web/about.php
